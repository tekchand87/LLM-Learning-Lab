# LLM Learning Lab

A hands-on learning repository documenting my journey of learning and building applications using Large Language Models (LLMs).

## Objectives

- Understand LLM fundamentals and model configuration.
- Build AI-powered backend applications using Node.js and Express.
- Learn prompt engineering and structured outputs.
- Understand embeddings and semantic search.
- Explore vector databases and similarity search.
- Implement Retrieval-Augmented Generation (RAG).
- Build document-based AI applications.
- Understand conversation history and context management.
- Apply production-ready AI development practices.

## Mini Projects

| No. | Project                     | Concepts                                      |
| --- | --------------------------- | --------------------------------------------- |
| 01  | AI Text Assistant           | LLM API, prompts, Node.js, Express            |
| 02  | AI Configuration Playground | Tokens, temperature, context windows          |
| 03  | Structured Output API       | Prompt engineering, JSON validation           |
| 04  | Semantic Search Engine      | Embeddings, cosine similarity                 |
| 05  | Vector Search Demo          | Qdrant, top-K, metadata filtering             |
| 06  | Mini RAG Assistant          | Chunking, retrieval, generation               |
| 07  | Chat with Documents         | Document processing, citations                |
| 08  | Conversation Memory API     | Chat history, MongoDB                         |
| 09  | Context Manager Demo        | Summarization, token budgets, query rewriting |

## Technology Stack

- Node.js
- Express.js
- Google Gemini API
- MongoDB
- Qdrant
- JavaScript
- TypeScript (where applicable)

## Learning Approach

Each mini-project focuses on a specific concept. The goal is to understand the architecture, implementation, API flow, and code rather than simply generate an application.

## Future Goal

After completing these mini-projects, I plan to combine the concepts into a larger project: **DocuChat AI**.
